🔗 本项目基于 [Sapphire](https://github.com/cshariq/Sapphire) 二次开发，增加中文适配、AI 额度查询与 Helper 连接修复。

Apple 芯片 · 项目最低 macOS 14.6 · DMG 直接安装，无需 Xcode 或 App Store。🔓 当前未公证，首次如被拦截，按[教程](README.md#首次打开被系统拦截)在「隐私与安全性」手动允许。
