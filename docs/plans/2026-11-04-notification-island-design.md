# 系统通知上岛

用户范围：所有应用通过 macOS 通知中心投递的通知，不局限于飞书。应用自行绘制的模态框、网页弹窗不属于系统通知。

复用 NotificationManager 的只读通知数据库、NotificationLiveActivityView 和 LiveActivityManager。普通通知不再默认被验证码过滤器排除；旧配置提供显式的“显示所有应用通知”入口，不静默覆盖用户原有过滤设置。

连接失败必须在设置页可见，提供完整磁盘访问入口和重试；应用重新激活及低频检查时恢复连接。监听数据库目录与 WAL，低频检查补偿 WAL 替换和漏事件。连接时记录开始时间，不回放历史通知；按投递时间读取最近窗口并去重，兼容延迟补齐投递时间的记录。

以有界 FIFO 保存通知，单条关闭或超时后展示下一条，异步按钮只能关闭它所属的通知。OTP 继续使用现有优先视图，但只从队首取出，避免重复上岛。关闭总开关或应用过滤后清除相应待展示项。

隐私边界：只读系统记录，不修改系统通知设置、不关闭系统横幅、不额外读取源应用的私有聊天数据库。锁屏由现有最高优先级活动控制。正文来自系统记录，首版尚未验证与系统“隐藏预览”策略完全同步。系统通知数据库属于 macOS 实现细节，权限和系统版本兼容性需实机验收，不能承诺任意程序自行绘制的弹窗都可捕获。

验证：用合成 plist 和通知事件验证解析、FIFO、重复事件、延迟关闭与容量边界；使用完整 Xcode 编译。当前进程无法访问真实通知数据库，实机全链路验证单独报告。
