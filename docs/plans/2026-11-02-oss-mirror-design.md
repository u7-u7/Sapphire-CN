# Sapphire-CN 安装包 OSS 镜像

用户选择阿里云 OSS 承载安装包下载镜像。网站和 GitHub 项目说明优先提供 OSS，保留 GitHub Releases 备用入口。本次不重新构建应用，也不改变已发布客户端仅接受 GitHub 域名的更新通道。

使用现有杭州标准存储 Bucket `sapphire-cn`，按 `releases/<tag>/<filename>` 保存已公开发行的 DMG、更新 ZIP、SHA256SUMS 和安装说明。Bucket ACL 保持私有，仅发行对象公共只读；不开放匿名列目录与写入，不启用 CDN、加速或额外资源。

发布脚本从 GitHub API 读取上传状态、大小、SHA-256，并核对本地文件。先以私有对象上传，再验证对象大小、摘要元数据和单次上传 MD5；发布时开放对象读取，进行匿名完整下载并核对 SHA-256。全部通过后才写入网站镜像清单。路径不可覆盖不同内容，凭据只在本机进程中读取。

生成器读取镜像清单构建主下载与网站专用 release 数据，同时保留 GitHub 备用链接。无镜像的历史版本继续下载 GitHub。应用更新清单 `updates/releases.json` 保持原地址。网站沿用 Workbench 增量发布，先备份再原子替换，核对所有远端静态文件摘要。

验证包括镜像 URL/摘要边界检查、四个附件公开下载摘要、Bucket 匿名列目录 403、生成页面主备链接、旧更新清单未改变，以及线上页面浏览器检查。回退时移除该版镜像记录并重新生成网站即可。
