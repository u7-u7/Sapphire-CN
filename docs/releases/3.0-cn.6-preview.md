# Sapphire-CN CN6：新团队签名迁移与中文修复

标签：`v3.0-cn.6-preview`。Apple 芯片 arm64，项目最低 macOS 14.6。主应用系统版本 `3.0 (6)`，签名内 CN 发行标识 `3.0-cn.6-preview`。

## 旧用户需要手动安装一次

**CN4 及更早版本、CN5 临时签名版用户，都需要先手动安装本版。** 主程序、Helper 和嵌入组件切换为新团队 `462JAMGP66` 的 Apple Development 证书签名；旧 CN4 团队为 `9CN6NKVEFU`。同团队签名校验保持启用，旧版无法直接通过应用内安装跨团队升级。

1. 退出应用，备份旧 `Sapphire.app` 和原安装包。
2. 下载本版 DMG，把完整应用拖入 Applications 替换；ZIP 仅含完整应用，也可解压后手动安装。
3. 从 `/Applications/Sapphire.app` 打开，并检查原已授权的辅助功能、后台运行等权限。签名变化可能触发重新批准。
4. 若旧团队 Helper 无法连接，请在“设置 → 电池 → 配置”中重新配置辅助服务，并按系统提示完成授权。
5. 完成迁移后，后续同一新团队签名版本可继续使用应用内更新；安装仍需本人确认。

## 本版更新

- 补齐 160 条中文翻译，覆盖通用设置、开发任务监测、存储、电池、壁纸和播放器选项。
- 修复已有翻译却仍显示英文的动态标签、下拉选项及滑块名称。
- Guest / Free 显示为“访客 / 免费版”。
- 账户页明确说明公开构建不包含账户登录与订阅管理。
- 主应用 build 递增至 6，主程序和 Helper 使用同一新团队签名并带安全时间戳。
- 保留原有下载摘要、架构、版本、同团队签名校验与 Helper/XPC 安全检查；未放宽校验以允许跨团队安装。

## 验证与边界

- 完整 Debug arm64 构建、中文资源编译通过。
- 对照已发布 CN4，保留各嵌入组件的权限声明；Helper 使用空权限声明并保留 hardened runtime。主程序未加入 CN4 安装包中不存在的受限权限声明。
- 使用真实 Security framework 的 `SecStaticCodeCheckValidity`，按更新器的严格标志检查主程序和 Helper；证书链有效、团队均为 `462JAMGP66`，应用标识保持不变。
- DMG 校验与只读挂载、ZIP 完整性、解包签名、版本、arm64 架构及主程序/Helper 哈希检查。
- 本版仍为 Apple Development 签名、未公证的开发预览，公开源码中订阅、系统扩展等占位功能不会因重新签名而成为完整实现。
- 整机重启、其他 Mac、跨团队旧 Helper 实际迁移、未来版本完整自动升级尚未验收。静态验证不等于上述场景已经通过。
