# Sapphire-CN CN10：系统通知上岛与前台免打扰

标签：`v3.0-cn.10-preview`。Apple 芯片 arm64，macOS 14.6 起。系统版本 `3.0 (10)`，签名内发行标识 `3.0-cn.10-preview`。

## 更新内容

- 系统通知上岛使用通用通知链路，覆盖通过 macOS 通知中心投递的应用消息；不局限于飞书或微信。应用自绘对话框不在范围内。
- 新配置默认显示普通通知；旧配置保留原来的筛选选择，可在通知页点击“显示所有应用通知”切换。
- 来源应用正在前台时跳过其提醒，切回应用时清除它当前及排队的通知，离开后不补播。支持同一应用包内的通知助手。
- 连续通知按队列展示，关闭或超时后显示下一条；修复旧弹窗的延迟关闭误关新通知的问题。队列最多保留 100 项，保留当前展示项，洪峰时淘汰最旧待展示项；过期项不补播。
- 通知页显示连接和权限状态，支持重新连接。文件监听结合低频检查，处理授权恢复、WAL 替换及延迟投递。
- 保留验证码专用展示与去重，新增应用菜单“设置”和 `⌘,` 快捷入口。
- 沿用 CN9 的 OSS 优先更新和 GitHub 回退，以及此前的中文适配、额度查询与权限入口修复。

## 首次使用与避免重复提醒

1. 在“系统设置 → 隐私与安全 → 完全磁盘访问权限”中允许 **Sapphire**；必要时退出重开。应用自己的“通知权限”不能替代读取系统通知所需的权限。
2. 在 Sapphire“通知”页确认正在监听。旧配置若只显示验证码，可点“显示所有应用通知”。
3. 如需只在岛上提醒，在“系统设置 → 通知 → 对应应用”取消“桌面”，保留“允许通知”和“通知中心”。此系统设置按应用保存，退出 Sapphire 后仍然生效；新应用需单独配置。

安装包不会替用户授予权限，也不会自动关闭各应用的原生横幅。升级后若出现钥匙串访问提示，请在系统窗口自行认证，不要在问题反馈中提交密码或通知正文。

通知链路只读本机 macOS 通知记录，没有加入上传通知正文的代码。完全磁盘访问权限范围较大，请按实际需要授权。

## 升级方式

**CN6–CN9 可通过“设置 → 关于 → Sapphire 更新”升级，也可从安装页手动下载。** CN9 优先从 OSS 获取；CN6–CN8 旧客户端本次仍使用 GitHub。CN4 及更早版本、CN5 临时签名版需手动安装一次，迁移到团队 `462JAMGP66`。
