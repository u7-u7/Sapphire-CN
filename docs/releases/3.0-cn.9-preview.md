# Sapphire-CN CN9：应用内更新优先使用 OSS

标签：`v3.0-cn.9-preview`。Apple 芯片 arm64，macOS 14.6 起。系统版本 `3.0 (9)`，签名内发行标识 `3.0-cn.9-preview`。

## 更新内容

- 更新清单和安装包优先使用阿里云 OSS，连接或 HTTP 失败时回退 GitHub。
- 镜像只接受 Sapphire-CN 专用 Bucket 的 HTTPS 地址，发行标签、文件名和摘要必须与原 GitHub 资产匹配；缓存与 ETag 绑定来源。
- 取消下载不会触发自动换源，大小、SHA-256 或归档校验失败会报错。保留发行版本、build 单调递增、arm64 和真实同团队签名检查。
- 保留 CN8 的 Codex 桌面版内置 CLI 识别和 CN7 权限设置入口修复。额度查询不发起模型任务，不替用户登录或复制凭据。

## 升级方式

**CN6、CN7、CN8 可通过设置 → 关于 → Sapphire 更新升级 CN9。旧客户端这一次仍从 GitHub 下载；安装 CN9 后，后续更新优先使用 OSS。也可从网站 OSS 镜像手动安装。**

CN4 及更早版本、CN5 临时签名版需先退出并备份原应用，再手动安装一次 CN9 迁移到团队 `462JAMGP66`。跨团队迁移后如 Helper 连接失败，请重新配置辅助服务并检查后台运行权限。

## 验证与边界

- 完整 Debug arm64 构建通过；47 项离线更新路由、清单兼容、下载回退/取消检查通过。
- 主应用与 Helper 沿用有效 Apple Development 证书和权限声明，安全时间戳签名；真实 Security framework 严格校验嵌套代码、标识与团队通过。
- DMG 只读挂载与 ZIP 解包校验通过；ZIP 仅含完整应用，路径和软链检查通过；中文资源、主程序/Helper 摘要一致。
- CN8 与 CN9 主应用和 Helper 的 designated requirement、权限声明一致，主应用 build 8 → 9。
- 仍为未公证开发预览，完整自动安装、其他 Mac、整机重启与故障网络下的实际回退仍需安装后验收；系统扩展等占位功能范围不变。
