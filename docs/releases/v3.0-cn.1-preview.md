# Sapphire-CN 3.0-cn.1 开发预览发行记录

发布标签：`v3.0-cn.1-preview`。目标仓库为 `u7-u7/Sapphire-CN`，标为预发布，不设为稳定最新版。

## 内容与签名

- 完整应用来自本机已验收的 `Sapphire.app`，内部版本 `3.0 (1)`，主程序与 Helper 均为 arm64。
- 主程序 UUID：`1448B3A9-15EB-3D26-9E8A-4E0F12BE590D`；核心握手修复来自 `19c57db`，打包前仓库提交为 `824bec2`，之后本次只更新发行与安装文档。
- Apple Development 开发签名；主程序与 Helper 身份匹配，严格深度校验通过。
- 无 Developer ID 分发证书；未完成 Apple 公证，Gatekeeper 实测拒绝。主程序没有 hardened runtime，因此本包不能标为正式公证发行版。
- 本机运行环境为 macOS 27.0.1。项目最低部署版本为 macOS 14.6，但跨机器、其他系统与整机冷启动未验收。

## 打包与验证

- 复制完整应用到独立暂存目录，未复制用户钥匙串、CLI 登录文件、个人设置或剪贴板历史。常见敏感文件与资源模式检查未发现这些内容；不把该检查宣称为任意二进制秘密的完整证明。
- DMG 中包含应用、指向 `/Applications` 的链接、中文安装说明和 AGPL-3.0 许可证。
- ZIP 中包含相同应用、说明、许可证及目录链接；不是仅有源码的 ZIP。
- 镜像 CRC 校验通过；只读挂载后再次验证签名、主程序与 Helper 哈希、中文资源和目录链接。
- ZIP 解压后严格签名验证通过，主程序与 Helper 哈希与原验收包相同。
- 本机应用重启后真实首次 ping 成功，协议 `11 / 11`，Helper 未重注册；15 秒延迟的 14 项匿名 XPC 检查另行通过。
