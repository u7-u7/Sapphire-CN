# Sapphire-CN CN7：权限设置入口修复

标签：`v3.0-cn.7-preview`。Apple 芯片 arm64；项目最低 macOS 14.6。主应用系统版本 `3.0 (7)`，签名内发行标识 `3.0-cn.7-preview`。

## 本版修复

- 修复屏幕录制、完全磁盘访问等权限此前请求过但未授权时，权限行只显示红叉、没有继续操作入口的问题。
- 未授权的权限行保留红色状态图标，并增加“打开隐私设置”按钮。屏幕录制、完全磁盘访问、辅助功能、蓝牙分别进入对应系统页面；通知进入通知设置，其余进入隐私设置。
- 首次请求屏幕录制后，立即根据系统返回值更新界面。未请求时仍显示“请求权限”，已授权时保留绿色状态图标。
- 沿用中文资源中的“打开隐私设置”翻译，启动引导与关于页面共用的权限行同时受益。
- 本次修复不会自动授予权限、清空旧授权记录，也不会绕过 macOS 隐私限制。系统如要求退出并重新打开应用，请按提示操作。

## 如何升级

**CN6 用户可通过“设置 → 关于 → Sapphire 更新”获取 CN7，也可手动安装。** CN7 沿用 CN6 的团队 `462JAMGP66` 证书，主程序与 Helper 同团队签名。

**CN4 及更早版本、CN5 临时签名版用户需手动安装一次 CN7。** 先退出并备份旧应用，再将完整 `Sapphire.app` 安装到 `/Applications`。这些旧版本的签名团队或签名类型不同，无法直接通过同团队校验自动安装本版。

跨团队迁移后如 Helper 无法连接，请在“设置 → 电池 → 配置”中重新配置辅助服务，并检查后台运行及相关权限。完成迁移后，后续同一新团队签名版本可继续使用应用内更新。安装始终需要本人确认。

## 验证与边界

- 完整 Debug arm64 构建通过，主应用 build 递增至 7。
- 沿用 CN6 各组件权限声明，由内向外统一证书签名，保留安全时间戳与 Helper 的空权限声明和 hardened runtime。
- 使用真实 Security framework 严格检查主程序和 Helper 的证书链、应用标识、团队与嵌套代码。
- 校验 DMG、只读挂载后的签名、ZIP 完整性和归档路径、解包后的签名、版本、arm64 架构、中文资源及主程序/Helper 哈希。
- 核对当前已安装 CN6 与 CN7 的团队、应用标识及 designated requirement 一致，主应用 build 单调递增；这是静态兼容性检查，不代表完整自动安装已经实测。
- 未通过测试操作真实系统权限开关；各授权状态的实际交互及完整自动升级仍需用户安装后验收。
- 本版仍为 Apple Development 签名、未公证开发预览。其他 Mac、整机重启及公开源码中的占位功能不在本次验收范围。
