# Sapphire-CN 3.0-cn.3 开发预览发行记录

发布标签：`v3.0-cn.3-preview`。目标仓库为 `u7-u7/Sapphire-CN`，保持预发布，保留旧版本安装包。

## 本次修复

- 验证码识别要求明确的验证码、OTP、verification code 等标签；普通聊天中的工作编号不再触发专用弹窗或自动复制。
- 支持中文标签紧邻数字及常见英文验证码语序，避免从长号码或字母数字编号中截取验证码。当前识别范围为带明确标签的 4–8 位数字；无标签裸数字不作为验证码。
- 补齐验证码事件的展示、关闭和消费状态，加入短期去重及旧通知过期限制，关闭后不再重复展示同一旧通知。
- 当前事件保持到主动关闭或超时；复制延迟回调及计时器核对事件标识，避免旧弹窗回调误关新弹窗。

## 本机实际验证

使用真实飞书机器人私聊投递、macOS 系统通知入口、已安装应用的原生界面和系统剪贴板验证：

- 普通工作消息不会误弹验证码，且不覆盖剪贴板。
- 验证码消息正常弹出，点击复制后剪贴板数字正确。
- 开启自动复制后，不点击按钮即可复制，界面显示 `Copied`；收起后不重复覆盖剪贴板。
- 单独点击 X 可立即关闭；关闭后继续等待超过原 20 秒展示周期，并接收新普通通知，没有重弹或重复复制。
- 自动复制关闭时，不点击任何按钮，弹窗可自然超时收起；再等待并接收普通通知后没有重弹。
- 验证后已恢复原自动复制设置和剪贴板。验证数字仅用于通知交互回归，不代表对第三方登录认证服务的验收。

仅在当前 Apple 芯片 Mac 完成上述实测；其他 Mac、Intel、其他系统版本及整机重启未验收。本次未新增测试用例。
