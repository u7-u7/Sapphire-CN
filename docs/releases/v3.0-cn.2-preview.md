# Sapphire-CN 3.0-cn.2 开发预览发行记录

发布标签：`v3.0-cn.2-preview`。目标仓库为 `u7-u7/Sapphire-CN`，保持预发布，保留上一版安装包。

## 本次修复

- 设备与有效增益相同时复用麦克风采样，避免状态通知触发反复停止、启动。
- 检测到停用后等待 500 毫秒重新读取；恢复使用会取消确认，明确设备不可用时仍立即释放采样。
- 麦克风使用和静音状态只在值变化时通知界面，减少重复刷新。
- 用户在本机实际录制后确认图标交替与位置跳动问题恢复正常。

## 构建与运行验证

- 完整 Debug arm64 构建成功，源码修改与本机安装验收版本一致。
- 主程序与原安装版的 105 项动态库依赖一致；仅替换主程序，保留既有 Helper、扩展及资源。
- 主程序 UUID：`B3844540-85C9-3445-A731-532CA27D72B5`；应用内版本仍为 `3.0 (1)`，通过新的 CN 发布标签区分。
- 主程序与 Helper 使用同一 Apple Development 签名身份，严格深度校验通过。
- 应用重启后首次 Helper ping 成功，协议 `11 / 11`、兼容性为当前版本，Helper 进程未更换。
- 本次未新增测试用例；用户实录确认通过。其他 Mac、Intel 与整机重启未验收。

## 打包与签名

- DMG 和 ZIP 均包含完整已验收应用、Applications 目录链接、中文安装说明与 AGPL-3.0 许可证。
- DMG 镜像校验及只读挂载检查通过；ZIP 解包检查通过。两种格式中主程序与 Helper 的哈希均与已安装验收包一致，严格签名与中文资源检查通过。
- 只打包应用目录，未包含用户设置、剪贴板历史、CLI 登录文件或钥匙串；常见个人数据与私钥文件名检查未发现额外内容。
- 沿用 Apple Development 开发签名，未完成 Apple 公证，不作为正式 Developer ID 分发包；项目最低 macOS 14.6，本包仅提供 arm64。
