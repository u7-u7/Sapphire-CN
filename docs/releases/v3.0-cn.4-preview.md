# Sapphire-CN 3.0-cn.4 换源开发预览

标签：`v3.0-cn.4-preview`。目标仓库：`u7-u7/Sapphire-CN`。沿用未公证 arm64 预发布，保留旧版。

## 首次迁移

**CN1–CN3 用户须先手动安装一次本版或更高换源版。** 已发旧程序硬编码上游地址，无法仅靠本仓库发布更新远程修改。换源后，后续版本可通过「设置 → 关于 → Sapphire 更新」检测、下载并由本人确认安装。

## 本版更新

- 主应用检查、下载、发行说明、About 和首次启动入口统一使用本仓库。
- 固定 CN GitHub 更新通道，包含公开预发布；不使用上游付费 Beta 通道限制。
- 发行标识为 `3.0-cn.4-preview`，系统营销版本为 `3.0`，主应用 build 为 `4`。CN 标识用于排序和候选校验，递增 build 兼容旧 Helper；未修改 Helper/XPC 协议。
- 缓存、ETag、调度及保存的更新候选改为 CN 独立命名，避免恢复上游下载。
- 应用内优先下载 `-update.zip`，该 ZIP 仅含完整应用，不带安装目录外链；也可解压后手动安装。
- 保留下载大小、摘要、归档路径和架构校验；主进程更新安装边界改用真实系统签名验证，核对同一应用、同一开发团队以及版本/build 单调升级。
- 保留上一版已实测的验证码误识别与重复弹窗修复。

## 构建和发布前验证

- 完整 Debug arm64 构建通过，未新增测试用例。
- 实际 Security framework 返回成功，签名内 CN 版本为 `3.0-cn.4-preview`、build 为 `4`，开发团队与原安装包一致。
- DMG 校验、只读挂载、解包后签名/版本/主程序与 Helper 哈希/中文资源检查通过。
- 更新 ZIP CRC、独立应用根目录、相对软链、解包签名和版本/哈希检查通过。
- 主程序 SHA-256：`7c62a6c0ec43f0a9b07b1dbbb5fd57a7114b72c77c4885cf9fd853ea39e004ac`。
- 真实 GitHub 应用内检查、下载和升级验收会在本预发布可下载后完成，结果另行记录；上述静态与本机打包检查不代替网络升级验收。
